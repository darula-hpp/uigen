C++ Apps

Hardware-oriented examples that expose REST APIs from C++ and drive UIGen from OpenAPI specs.

- [esp32-simulator](./esp32-simulator/) - Simulated ESP32 dev board with GPIO, sensors, and telemetry
- [stm32-nucleo-simulator](./stm32-nucleo-simulator/) - Simulated NUCLEO-F411RE with Arduino header pins, I2C sensors, and 4-20mA input

For a generic, Vercel-deployable variant see [Next.js DevBoard](../nextjs/devboard-simulator/).
